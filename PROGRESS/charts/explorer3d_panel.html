3D Metric Explorer
Pick any metric for X / Y / Z, color and bubble size. Drag to rotate, scroll to zoom, click a point to inspect the class. Hover shows raw values (log axes are labelled with raw values too).
Click a point (or a row in the Top 10 / All Classes tables) to see every metric of that class, its percentile versus all production files, co-change partners, knowledge-loss flags and clones.
Metric Correlations (Spearman ρ, all production Java files)
How strongly does one metric move with another? ρ = +1: always rise together, 0: unrelated, −1: one rises as the other falls. Spearman uses ranks, so it is robust to the heavy outliers in this codebase. Click any cell to open that pair as X / Y in the 3D Explorer.
Strongest relationships between different metric families
Pairs inside the same family (e.g. 24m vs. 12m commits, Cog Sum vs. Cog Max) are left out because they are related by construction.
